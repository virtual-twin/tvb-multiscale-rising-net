# Data and software scripts for publication Geminiani, Meier, Perdikis et al. 2026


## data
Data files and notebooks for generating the connectome used for simulations 

### oh_table1.xls
Original information of the brain regions' labels used in the study.

### interacting_with_Allen.ipynb, interacting_with_Allen-from_TVB_project.ipynb
Notebooks used for generating the connectome (see Methods 4.1 of the main manuscript and Supplementary Tables S1 & S2)

### popa2013
M1 and S1 power spectral density and coherence data extracted from Popa et al 2013 
to be used as targets for fitting the model

### wTVBtoNESTparams.pkl
File with the TVB to NEST interface tuned parameters' values

### wNESTtoTVB
Folder with files of the NEST to TVB interface tuned paramers' values per global scaling parameter G value.


## scripts
Python package that implements the specific code used for simulations, fitting and plotting.

### ./round_0/plot_S8fig_FIT_TASK.ipynb
Notebook to produce Supplementary Figure S8

## bash_scripts
Used for simulations in the BIH cluster
